# Faulty Calculator

A quirky web-based calculator that occasionally provides "faulty" results for added fun! This project is a playful twist on a traditional calculator, designed to demonstrate creative JavaScript logic and responsive web design.

## Features

- **Basic Calculator Functions**: Supports addition, subtraction, multiplication, and division.
- **Faulty Mode**: Introduces random quirks by altering operations (e.g., `+` might behave as `*`) in 25% of the calculations.
- **Responsive Design**: Optimized for desktop and mobile devices.
- **User-Friendly Interface**: Clean layout with intuitive button placement.

## Tech Stack

- **HTML**: Structure and layout of the calculator.
- **CSS**: Styling for the calculator's design and responsiveness.
- **JavaScript**: Handles user input, performs calculations, and introduces "faulty" behavior.
